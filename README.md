# 🇸🇦 نظام إدارة الموارد البشرية والعهد (HR & Custody Management Demo)

## 📌 نظرة عامة على المشروع (Project Overview)
نسخة تجريبية (Frontend Demo) لتطبيق ويب مخصص لإدارة الموارد البشرية (HR) وإدارة العُهد (Custody Management) مصمم خصيصاً ليتوافق مع نظام العمل السعودي والبروتوكولات الإدارية المتبعة في الشركات المحلية، مع التركيز على متطلبات الامتثال لمنصات (قوى، مدد، التأمينات الاجتماعية).

- **المؤلف:** Malek Sultan Allehabi
- **بيئة العمل:** الواجهة الأمامية (Frontend Only) - ديمو تفاعلي.
- **التصميم الأساسي:** دعم كامل للغة العربية من اليمين لليسار (RTL Support) كوضع افتراضي.

---

## 🛠 التقنيات والأدوات (Tech Stack)
تم اختيار هذه الحزمة لضمان أداء عالٍ، كتابة كود نظيف، وقابلية للتوسع مستقبلاً للربط مع واجهات خلفية (Backend APIs):
- **الإطار الأساسي:** React 18+ مع Vite لسرعة البناء.
- **لغة البرمجة:** TypeScript (لضمان نوعية البيانات وتقليل الأخطاء).
- **إدارة الحالة (State Management):** Zustand (لخفة وزنه وسهولة استخدامه في إدارة بيانات الموظفين والعهد).
- **التنسيق وواجهة المستخدم (Styling & UI):** Tailwind CSS مع إعدادات مخصصة لدعم RTL.
- **النماذج والتحقق (Forms & Validation):** React Hook Form مع Zod (للتحقق الصارم من الهوية السعودية وتواريخ الانتهاء).
- **التوجيه (Routing):** React Router DOM.
- **أدوات مساعدة (Utilities):** TanStack Query (مُجهز لمحاكاة جلب البيانات مستقبلاً)، ومكتبة تصدير لملفات CSV/Excel.

## 🎯 الميزات الأساسية (Core Features)

### 1. وحدة الموارد البشرية (HR Module)
- **ملف الموظف الكامل:** إدارة البيانات الشخصية، الجنسية (سعودي/غير سعودي)، وتفاصيل العقد (محدد المدة/غير محدد).
- **الامتثال والتحقق:** التحقق من رقم الهوية الوطنية/الإقامة (10 أرقام، تبدأ بـ 1 للسعودي و 2 للمقيم)، وتتبع تاريخ الانتهاء مع نظام تنبيهات مرئي.
- **التأمينات الاجتماعية (GOSI):** حساب الخصومات تلقائياً (خصم 9.75% من الراتب الأساسي + بدل السكن للسعوديين فقط).
- **حماية الأجور (WPS):** توليد مسيرات الرواتب الشهرية وتجهيزها للتصدير بصيغة CSV توافق متطلبات منصة "مدد" والبنوك السعودية.

### 2. وحدة إدارة العُهد (Custody Management)
- **تصنيف العُهد:** دعم العُهد العينية (سيارة، لابتوب، جهاز جوال) والعُهد المالية (سلفة نقدية، بطاقة بنكية).
- **دورة حياة العهدة:** 
  - `Active`: عهدة مسلمة للموظف (مع توقيع نموذج استلام).
  - `Returned`: عهدة مسترجعة للمستودع/الإدارة المالية.
  - `Lost/Damaged`: عهدة مفقودة أو تالفة (تتطلب رفع محضر).
- **تتبع المخزون:** لوحة تحكم (Dashboard) تعرض إحصائيات العُهد النشطة والمتأخرة.

### 3. نظام إخلاء الطرف (Clearance Protocol)
- **المنطق الشرطي الصارم:** واجهة مخصصة لنهاية الخدمة. النظام يمنع برمجياً (Disable) إصدار "مخالصة نهائية" لأي موظف ما لم تكن حالة **جميع** العُهد المرتبطة به محددة كـ `Returned`.
- **الربط التقاطعي (Cross-module Check):** جلب بيانات الإجازات المتبقية من قسم الـ HR، وحالة العُهد من قسم الإدارة المالية في شاشة واحدة.
